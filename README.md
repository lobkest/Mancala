# Mancala

A Java implementation of the domain logic for the classic board game **Mancala**, built as part of a traineeship project at Sogyo.

## About the project

This project was completed in **1.5 weeks** at Sogyo. It focuses purely on the **domain logic** of Mancala, implemented in Java. A front end was added later in a separate project, [`Mancala_MVC`](#).

## Approach

- **Test-Driven Development (TDD):** unit tests were written first, followed by the implementation needed to make them pass.
- **Object-oriented design:** the project is built in a fully object-oriented way, modeling the game's rules and state as classes and their interactions.
